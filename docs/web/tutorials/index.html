Tutorials

Complete animations from start to finish, from a linear equation to an annotated identity. Each one is a worked example: you see what it makes, download the project, and build it step by step.

The tutorials

They go from gentle to demanding. The basic ones start from your first animation; the later ones use features that the other sections of these pages teach.

What each tutorial gives you

A tutorial is more than a recipe. Each one ends with something you keep.

  • The finished animation, playing in the page, with its timeline.
  • The project, a .mfe.json file you download and open with File ▸ Open… and its Other file… button, to change or to check your work against.
  • The Python the editor exports for it, for ManimCE and ManimGL.
  • The video that ManimCE renders from that Python.
  • The steps to build it yourself, each shown in the editor.

You do not need Manim to follow a tutorial: the editor plays the animation itself. You need Manim only to run the exported Python (Exporting says how).

Levels

The level of a tutorial says what it asks of you.

LevelWhat it assumes
BasicOnly Your first animation: formulas, clips, an intro, a relation, an export.
IntermediateThe Basics and Transformations sections: relations in detail, styles, timing.
AdvancedFeatures beyond those sections, such as Morph blocks, braces and arrows.

Before you start

  • The editor open in your browser. If it is not running yet, see Getting the app running.
  • An empty project for each tutorial: File ▸ New.
  • The tour of the interface, if the names of the panels are new to you: the Creator, the Preview, the Animations panel and the Timeline.
